## About | درباره پروژه

**TickTask** is an Android application designed to help users organize their daily tasks, manage priorities, and stay focused on what matters.

TickTask aims to provide a clean, intuitive, and modern user experience through a simple interface and practical task management features.

**تیک‌تسک** یک اپلیکیشن اندرویدی برای مدیریت وظایف روزانه، اولویت‌بندی کارها و برنامه‌ریزی بهتر فعالیت‌هاست.

هدف این پروژه ارائه تجربه‌ای ساده، روان و مدرن است تا کاربران بتوانند کارهای خود را منظم‌تر مدیریت کنند و بهره‌وری بیشتری داشته باشند.

## Features | قابلیت‌ها

The following features are part of the project's development plan:

- Daily task management
- Task priorities and status tracking
- Modern Material Design interface
- Light and Dark themes
- Local data storage using Room
- MVVM architecture
- LiveData for reactive data updates
- Notifications and task reminders
- Task reports and statistics
- Customizable application settings

ویژگی‌های در نظر گرفته‌شده برای این پروژه:

- ثبت و مدیریت وظایف روزانه
- تعیین اولویت و وضعیت انجام کارها
- رابط کاربری مدرن بر پایه Material Design
- پشتیبانی از حالت روشن و تاریک
- ذخیره‌سازی محلی اطلاعات با Room
- معماری MVVM
- استفاده از LiveData
- اعلان‌ها و یادآوری وظایف
- گزارش‌ها و آمار فعالیت‌ها
- تنظیمات و شخصی‌سازی برنامه
